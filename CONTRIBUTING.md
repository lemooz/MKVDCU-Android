# Contributing

Thanks for helping improve the Android port.

## Reports and changes

- Search existing issues before opening a new one.
- Include device model, SoC, Android version, Vulkan driver and version, graphics settings, and concise reproduction steps.
- Share logs only after removing personal paths, account identifiers, and other private data.
- Never upload game images, decrypted game files, BIOS/keys, or copyrighted assets.
- Keep changes focused and explain which device or build you used to verify them.
- Do not claim a driver or device is supported based only on an APK build; include an on-device result.
