# Security policy

This is an experimental community port. Please do not publish security issues involving exploitable vulnerabilities, malicious driver packages, or unsafe file handling as public issues before coordinating a fix.

Open a private security advisory through the repository's **Security → Advisories** page. Include the affected release, device/Android version, reproduction steps, and impact. Do not send game files, private signing keys, or unrelated personal data.

There is no guaranteed response time while the project is maintained by one developer.
